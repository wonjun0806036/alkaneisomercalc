# 알케인 구조이성질체 계산기

탄소 원자 수를 입력해 알케인의 구조이성질체를 계산하는 브라우저 기반 학습용 도구입니다.

## 실행 방법

1. 저장소의 `index.html` 파일을 내려받습니다.
2. 웹 브라우저에서 `index.html`을 엽니다.
3. 탄소 원자 수 `n`을 입력하고 **계산**을 누릅니다.

현재 인터페이스의 입력 범위는 **1~6**입니다. 실행에 별도 서버나 패키지 설치는 필요하지 않습니다.

## 코드 구조

- `index.html`: 사용자 인터페이스와 계산 로직
- `script.js`: 별도 파일로 보관된 코드
- `js/`: 보조 자바스크립트 파일

## 수동 검증 항목

- `n=1`, `n=2`, `n=6` 입력 시 계산 완료 여부 확인
- 범위를 벗어난 값과 숫자가 아닌 입력에 대한 검증 확인
- 새 브라우저에서 실행해도 동일한 결과가 나오는지 확인

계산 결과의 과학적 정확성은 이 README 추가만으로 검증된 것이 아닙니다. 검증 데이터와 자동 테스트는 후속 작업으로 관리합니다.

## 개발 및 보안 원칙

기능 변경은 별도 브랜치에서 작업하고 Pull Request를 통해 `main`에 병합합니다. API 키, 비밀번호, 개인 데이터와 같은 인증·민감정보는 저장소에 올리지 않습니다.
